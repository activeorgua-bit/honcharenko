# Гончаренко: OSINT-матеріали

Розбори, документи та джерела проєкту, зібрані з відкритих даних. Сайт: https://activeorgua-bit.github.io/honcharenko/

## Розділи

- [Досьє: звʼязки Гончаренка](dossier/11651-core.html) — статичний знімок сервісу «Пошук звʼязків». Вхід — «Головне» (родина, помічники, їхні компанії, ГО, усі повʼязані партії, фінансувальники «Гончаренко центрів»); далі — повне досьє за деклараціями НАЗК із графом звʼязків до 4 рівнів (ЄДР, реєстр ГО, ЦВК, ЧЕСНО, ручні звʼязки з джерелами; шар «Експо-Грейн»/«Інагро»; глибші кола довантажуються з `dossier/data/11651-ego/`), звіти (одеський осередок ЄС і Партія регіонів, внески ГО «ВИ.МОВА», кримінальні справи оточення, справа СБУ щодо Паращенків, Леся Дерев'янко, Криворот). Дані — у `dossier/data/*.js`.
- [Дашборд цитувань Гончаренка](dashboard/) — Telegram-канали України й Росії (Telemetrio) і російська видача Google: тональність, звинувачення в роботі на РФ, схвалення тез про ТЦК і мир, канали; кожне число розкривається в перелік першоджерел. Джерело: `dashboard-src/`.
- [Гроші «Гончаренко центрів»](vymova/) — фінанси ГО «ВИ.МОВА» (ЄДРПОУ 43417706): витрати 2020–2025, реальна кількість центрів, хто офіційно названий донором і хто він за реєстрами, чи сходяться цифри; посилання на оригінали звітності на сайті мережі зі звіркою SHA-256.
- [Ешкрофт у файлах Епштейна](ashcroft/) — згадки лорда Майкла Ешкрофта в документах Мін'юсту США (реліз EFTA): сторінка розбору, повний аналіз, оригінали PDF зі звіркою SHA-256.
