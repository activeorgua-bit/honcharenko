# Цитування Олексія Гончаренка — дашборд

Статичний дашборд (Svelte 5 + Vite + Tailwind 4 + SveltePlot) над знімком даних Ghost (проєкт «Олексій Гончаренко»):
Telemetrio (українські й російські канали, 01.01.2025–03.10.2026) і російська видача Google (знімок 03.10.2026). YouScan не береться.
Зразок структури — f.ppl.watch (C:\Claude\fedorov\web): панелі з власними фільтрами, стан у URL, одне вікно першоджерел на весь дашборд.

**Правило:** будь-яке число можна розкрити — клік по сегменту графіка чи рядку таблиці відкриває перелік матеріалів, із яких воно пораховане,
з текстом, розміткою, доказом моделі й посиланням на допис. Перелік вивантажується у CSV.

## Сторінки
1. Загальна динаміка — KPI, обсяг за роллю/країною/темою, тональність матеріалів саме про нього, теми цитувань, категорії.
2. Звинувачення — у часі, хто звинувачує, у якому контексті (рос. пропаганда / популізм / корупція / зрада).
3. Схвалення тез — UA проти RU за тезою, у часі, канали-схвалювачі.
4. Канали — рейтинг і таблиця (сортування, поріг, пошук).
5. Google — датовані результати, джерела, повна таблиця.
6. Матеріали й набори — усі набори з лічильниками (корпус/нерелевантні/реклама/дублі), фільтри за всіма вимірами, пошук (у текстах — після довантаження), пагінація.
7. Методологія.

## Дані
`public/data/meta.json` (батчі, словники, канали), `public/data/items.json` (усі матеріали без тексту, колонками, ≈10 МБ),
`public/data/text/<shard>.json` (текст, доказ, резюме; шарди по 2000 id, довантажуються на вимогу, разом ≈73 МБ).
Оновлення знімка (на сервері Ghost, 65.109.239.159):
```
scp tools/export_dash.py root@65.109.239.159:/tmp/ && ssh root@65.109.239.159 'cd /opt/ghost && venv/bin/python /tmp/export_dash.py /tmp/dash_data && tar czf /tmp/dash_data.tgz -C /tmp dash_data'
scp root@65.109.239.159:/tmp/dash_data.tgz . && tar xzf dash_data.tgz && rm -rf public/data && mv dash_data public/data
```
Корпус = `relevant=1` без реклами (`is_ad`) і дублів (`dup_of`); відсіяне лишається в знімку й показується на вкладці матеріалів.
