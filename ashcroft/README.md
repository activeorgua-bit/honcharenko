# Ешкрофт у файлах Епштейна

Розбір згадок лорда Майкла Ешкрофта в документах, які Мін'юст США оприлюднив за Epstein Files Transparency Act (реліз EFTA). Слово «Ashcroft» трапляється на сотнях сторінок, але лорда стосуються лише чотири епізоди 2010–2013 рр. Контакту Ешкрофта з Епштейном не виявлено. Документи показують, що у 2010 р. Епштейн радив Пітерові Мендельсону, як атакувати Ешкрофта.

- Сторінка розбору: [index.html](index.html)
- Повний розбір (Markdown): [analysis.md](analysis.md)

## Застереження

Згадка в листуванні Епштейна не означає ні зв'язку з Епштейном, ні правопорушення. Щодо всіх згаданих осіб діє презумпція невинуватості.
